# Sistem Penilaian Mahasiswa

Repository ini merupakan proyek UAS Praktikum Pemrograman Web Dasar dengan studi kasus Sistem Penilaian Mahasiswa.

## Deskripsi
Sistem Penilaian Mahasiswa merupakan aplikasi berbasis web yang digunakan untuk mengelola data nilai mahasiswa, menghitung nilai akhir, menentukan grade, serta menampilkan statistik nilai mahasiswa.

## Teknologi yang Digunakan
- HTML5
- CSS3
- Bootstrap 5
- JavaScript
- jQuery
- PHP
- MySQL
- Chart.js

## Fitur Utama
- Menampilkan daftar mahasiswa dan nilai.
- Menambahkan data nilai mahasiswa.
- Menghitung nilai akhir secara otomatis.
- Menentukan grade berdasarkan nilai akhir.
- Menampilkan statistik nilai.
- Filter dan sorting data.
- Menghapus data dengan konfirmasi.
- Menampilkan grafik distribusi grade.
